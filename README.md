# Оборона Гадюкино — сайт серии игр

Страница на GitHub Pages: https://gadyukino.github.io/ — все три части, подробно часть 1 и часть 2.
Лендинг третьей части «Чародол» — отдельный репозиторий `gadyukino/charodol`: https://gadyukino.github.io/charodol/

Картинки в `img/`: `p1/` — обложки глав из `Downloads/Home/Gadyukino-art/glava-N/` и снимки боя из текущей игры (12.11.2026, главы с новой графикой), `p2/` — обложки и снимки второй части (`Gadyukino2-art`, `Gadyukino2-RuStore/raw`), `p3/hero.jpg` — заставка Чародола. `og.jpg` собран из трёх обложек.
Когда часть 2 выйдет в RuStore (ru.gadyukino.oborona2), заменить «Скоро в RuStore» на ссылку и дописать downloadUrl в JSON-LD.
